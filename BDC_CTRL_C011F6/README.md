# BDC_CTRL 电机控制框架

## 框架概述
基于双闭环控制的电机驱动系统，核心计算使用 `float32_t` 数据类型，支持力矩/速度/位置三种控制模式。
系统基于HAL库开发

## 核心模块
### 1. bdc_motor - 主控制器
- **功能**：电机总控逻辑实现
- **架构**：
  - 双闭环控制系统

  - **阻抗环**：IMP 控制 @ 1kHz
    - **设置**：设置 `float32_t` 格式比例参数，注意量纲匹配
    - **输入**：施加 `float32_t` 格式位置（r）、速度(r/ms)、力矩（mNm）信息
    - **输出**：返回 `float32_t` 格式期望扭矩值（mNm），通过电机常数计算得期望电流值

  - **电流环**：PID 控制 @ 10kHz
    - **设置**：设置 `float32_t` 格式比例参数，注意量纲匹配
    - **输入**：施加 `float32_t` 格式电流信息，单位mA
    - **输出**：返回 `float32_t` 格式线电压比例值，范围[-1, 1]，转为 `q15_t` 后控制线电压

- **控制模式**：
  - 力矩控制
  - 速度控制
  - 位置控制
- **输出**：PWM 信号 @ 20kHz 静音运行

### 2. imp_controller - 阻抗控制器
- **实现**：阻抗控制算法
- **数据类型**：`float32_t`

### 3. pid_controller - PID 控制器
- **实现**：PID 控制算法
- **数据类型**：`float32_t`

## 硬件驱动层
### 4. drv8213_driver - 电机驱动器
- **功能**：驱动 DRV8213 电机驱动器
- **输入**：施加 `q15_t` 格式线电压控制信号
- **输出**：返回 `float32_t` 格式电流信息，单位mA

### 5. ma782_driver - 位置编码器
- **功能**：MA782 编码器数据采集
- **输出**：返回 `q15_t` 格式位置信息

### 6. utils_driver - 实用工具
- **功能集合**：
  - 电机温度测量
  - 线电压监测
  - 状态指示灯控制
