# 触觉采集板通信说明

USART1 使用 PB6（TX）和 PB7（RX），460800 bit/s、8N1。主控 USART2 TX 接所有触觉板 RX，所有触觉板 TX 接主控 USART2 RX，各板共地。每块板须在 `tactile_sense/com.h` 中设置不同的 `SENSOR_BOARD_ID`，范围为 0～11，再分别编译烧录；默认值不代表其余板已配置。

- 主控发送 `AA 55 01 ID CHECK8`，`CHECK8` 为前 4 字节之和的低 8 位。只有校验通过、命令为 `01` 且 ID 与本板一致时才应答。
- 应答为 79 字节：`FF 66`、ID、2 字节大端帧计数、36 个大端 uint16 触觉值、2 字节大端累加校验。校验是前 77 字节之和的低 16 位。应答使用最近一次完整采样快照。
- 上电后尽早将 PB6 设为带弱上拉的输入；有效应答开始时切换推挽输出，UART 物理发送完成后释放为输入。79 字节在 460800 bit/s 下理论耗时约 1.72 ms；正常发送应在主控 4 ms 槽期内完成。发送异常时主循环在系统计时相差至少 3 ms 后尝试释放并恢复；因计时粒度及任务调度，这不是硬实时上限。
- 必须用示波器在实际板数、线长和负载下检查共享 TX 总线的空闲高电平、低电平、上升沿和应答窗口。内部上拉较弱，是否需要合适的外部上拉应通过电路计算和实测确定。主控与板卡启动不同步、复位、掉电、程序卡死或迟到应答时，软件三态不能保证无争用或电气隔离。
- 该说明仅覆盖从板逻辑；主控 DMA、USB 转发、上位机解析、板号和接线都必须正确，不能仅凭从板编译通过认定整条链路已恢复。
